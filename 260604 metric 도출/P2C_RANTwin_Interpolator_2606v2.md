# P2C_RANTwin_Interpolator_2606v2.py

## 목적 (v1→v2)
v1에서 학습(GP/MLP)과 단순보간(IDW)의 격차가 작았던 것을 키우기 위해, 디지털트윈의
'실측 후 업데이트' 개념을 도입. 학습 모델 입력에 **싸게 측정 가능한 값(다중 BS
RSRP, 평균지연)** 을 추가하여 비싼 전체 채널(PDP+재구성 Cov)을 추론.

## 비교
| 기호 | 입력 | 학습 |
|---|---|---|
| 단순보간 IDW | 위치(x,y)만 | 없음(baseline) |
| RAN Twin kNN | 위치 + RSRP(3) + 평균지연(3) 표준화 공간 | 있음 |
| RAN Twin MLP | 동일 context(8) → 채널분포 회귀 | 있음 |

## 결과 (n=900, 3-BS, 시드4, floor≈0.738) — **가설 기각(negative)**
| 관측비율 | S: IDW(위치) | S: kNN(위치+실측) | S: MLP(위치+실측) |
|---|---|---|---|
| 10% | **0.812** | 0.797 | 0.802 |
| 50% | **0.860** | 0.845 | 0.849 |
| 90% | **0.874** | 0.860 | 0.863 |

- **위치-only IDW가 전 구간 최고.** 측정값(RSRP·지연) 추가가 오히려 성능을 떨어뜨림.

## 원인 분석 (중요)
1. **채널은 위치의 매끄러운 함수** → 정확한 위치를 알면 위치 보간이 거의 최적.
2. RSRP·평균지연은 본질적으로 **위치(거리)와 상관** → 새 정보가 거의 없음.
3. 표준화 context 거리에 RSRP/지연을 섞으면 **위치 정보가 희석** → 이웃 선택이
   공간적으로 틀어져 보간 품질 저하. (잡음만 추가)
4. 결론: **정확한 위치가 주어진 환경에서는 단순 위치보간이 강한 baseline이고
   ML이 이를 능가하기 어렵다.** 개념도(학습≫보간)는 보간이 불리한 조건
   (위치 부정확/미상)에서만 실현 가능.

## 다음 방향 (학습이 실제로 이기는 재설계)
- (A) **위치 잡음(GPS 오차) 도입**: 위치보간은 잘못된 이웃을 고름 → RF 실측을
  융합하는 RAN Twin이 강건 → 학습 우위.
- (B) **위치 미사용(RF 핑거프린트만)**: 위치 없이 RSRP/지연→전체채널 학습.
  naive는 전역평균(floor) → 학습이 크게 앞섬.
