# P2F_AngularSectorization_2606v1

## 목적
P2E 클러스터가 연속 채널 장(continuum)이라 흐릿했던 문제를 **방위(AoA) 섹터화**로
가장 뚜렷하게 만든다. AoA가 지배 신호이므로 채널의 **지배 방위각(APS 원형평균)** 으로
묶으면 깔끔한 부채꼴 구역이 형성된다. 또한 채널 기반 섹터가 실제 기하 방위를 복원하는지
검증해 "채널이 위치(섹터)를 인코딩함"을 보인다.

## 방법
- **지배 방위각** : `θ_T = atan2(Σ aps_k sinφ_k, Σ aps_k cosφ_k)` (BS별 APS 원형평균)
- **집중도** : `R_T = |Σ aps_k e^{jφ_k}| ∈ [0,1]` (작을수록 방위 불명확)
- **군집 특징** : `[R_T cosθ_T, R_T sinθ_T]` (T=0,1,2) → 6차원, K-means
- **k 선택** : silhouette(euclidean), k=3~10
- **공정 비교 (b)** : 기하 방위도 채널과 **동일 방식**으로 군집 —
  3-BS 방위 `β_T=atan2(y−y_T, x−x_T)` → `[cosβ_T, sinβ_T]×3` 6차원 K-means(같은 k)
- **검증** : 채널 θ(BS0) vs 기하 방위 `β0=atan2(y−y0, x−x0)`
  - 정렬도 `R_align = |mean(e^{j(θ−β)})|` (일정 오프셋으로 추종하면 1에 근접)
  - 채널 군집 vs 기하 군집 `ARI`
- **색 맞추기** : 채널 군집 라벨 → 기하 섹터에 최대 겹침으로 Hungarian 재정렬
  (`linear_sum_assignment`) 후, 같은 색=같은 섹터가 되도록 (a) 재색칠 + 일치율(%) 표시

## 결과 (n=1500, 3-BS)
- **Silhouette = +0.308 (k=3)** — P2E 전체 채널거리 군집(0.10~0.12) 대비 **3배 또렷**.
- 물리지도: 채널 방위 군집이 **상단/좌측/하단의 일관된 공간 구역**으로 분리.
- **정렬도 R_align = 0.72, 오프셋 +174°(≈180°)** — 채널 지배 방위가 기하 방위를
  약 180° 반전 형태로 강하게 추종. 180° 차이는 물리적으로 당연(도래각 AoA는
  BS→RX 방향의 반대편에서 들어옴).
- 단순 원형상관(−0.18)은 이 180° 반전을 음수로 잘못 읽음 → 정렬도(R_align)가
  올바른 지표.
- **공정 비교(둘 다 3-BS 방위 + K-means) 결과**:
  - **ARI = +0.383**, **색 일치율(Hungarian 정렬 후) = 71.9%** (k=3 무작위 ~33% 대비 매우 높음).
  - 지도 (a)·(b)가 좌측(주황)·우상(파랑)·하단(초록)으로 **거의 동일한 형태** → 채널이
    지리 방위 구조를 잘 복원.

## 비교 기준에 따른 차이 (해석 주의)
- 초기엔 (b)를 **BS0 단일 등각 분할**로 두어 ARI=0.204·색일치율=49.8%로 낮게 나왔음.
  이는 채널이 안 묶여서가 아니라 (a)=3-BS / (b)=BS0-단일로 **정의가 달라** 생긴 과소평가.
- (b)도 (a)와 **동일 방식(3-BS K-means)** 으로 맞추자 ARI=0.383·일치율=71.9%로 상승.
- 라벨/색은 임의이므로 색 일치는 Hungarian 정렬 후 평가했고, 연속 각도 추종 지표
  `R_align=0.72`(오프셋 180°, 도래각 반전)가 가장 신뢰할 만한 척도 — 산점도 (c)의
  또렷한 대각선이 이를 뒷받침.

## 해석
- 방위 특징으로 군집하면 연속 장에서도 **뚜렷한 섹터**가 나온다(silhouette 0.31).
- 채널 방위는 기하 방위를 강하게(R=0.72) 추종 → 채널이 방향/위치 정보를 인코딩함을
  정량 확인. 빔포밍 섹터 그룹핑·핸드오버 영역 설정에 직접 활용 가능.
