NVIDIA L40S GPU 서버 설정 가이드

A. 하드웨어 정보

GPU 사양 (NVIDIA L40S × 2대)

  • GPU Memory: 48GB GDDR6 with ECC
  • CUDA Cores: 18,176개
  • Tensor Cores: 568개 (4th Generation)
  • Max Power: 350W
  • 총 구매가격: 24,200,000원 (VAT 포함)

서버 사양 (Supermicro SYS-740GP-TNRT)

  • CPU: Dual Intel Xeon Gold 6326 (16코어/32스레드)
  • Memory: 1TB DDR4-3200 ECC
  • Storage: 1.92TB NVMe SSD
  • Network: Dual 10GbE + 200G InfiniBand

C. 개발 환경 사용법

1. 프로젝트 파일 준비

클라이언트 PC에서 프로젝트 폴더에 다음 파일들을 준비:

프로젝트_폴더/
├── Dockerfile
├── .devcontainer/devcontainer.json
└── vscode-server-linux-x64.tar.gz

VS Code Server 파일에 대한 설명

vscode-server-linux-x64.tar.gz가 필요한 이유:

  1. 원격 개발 환경 구성: 원격 서버에 VS Code 환경을 구성하여 로컬 PC의 편리한 개발 인터페이스를 그대로 유지하면서 원격 서버 자원과 환경을 활용
  2. 효율적 개발: 로컬 PC와 원격 서버 간 파일 전송 없이 바로 서버에서 작업 가능
  3. 일관된 개발 환경: 다양한 개발 환경(컨테이너, 클라우드 VM, 사설망 서버 등)에서 동일한 IDE 경험 제공
  4. 최적화된 연동: 원격 서버의 운영체제 및 아키텍처에 맞는 서버 구성 요소를 설치하여 VS Code와 원활한 연동

수동 준비가 필요한 경우:

  • 인터넷 차단 환경: 원격 서버가 인터넷에 연결되어 있지 않거나 사설망(망분리 환경)인 경우
  • 자동 다운로드 불가: VS Code가 자동으로 서버용 설치 파일을 다운로드하기 어려운 환경
  • 보안 정책: 외부 다운로드가 제한된 환경

VS Code Server 파일 준비 방법:

  1. VS Code에서 commit ID 확인:

    # VS Code에서 Ctrl+Shift+P 후 "Developer: Reload Window"
# Help → About에서 Commit ID 확인

  2. 공식 저장소에서 다운로드:

    # 예시: commit ID가 6f17636121051a53c88d3e605c491d22af2ba755인 경우
wget https://github.com/microsoft/vscode-server/releases/download/6f17636121051a53c88d3e605c491d22af2ba755/vscode-server-linux-x64.tar.gz

  3. 프로젝트 폴더로 복사:

    # 다운로드한 파일을 프로젝트 폴더에 복사
cp vscode-server-linux-x64.tar.gz /path/to/your/project/

  4. SSH로 서버에 업로드:

    # 프로젝트 전체를 서버로 복사

E. 트러블슈팅

일반적인 문제

1. GPU 인식 불가

  • 증상: nvidia-smi 명령이 작동하지 않음
  • 해결: 드라이버 재설치 또는 재부팅 필요

2. Docker 권한 오류

  • 증상: permission denied while trying to connect to the Docker daemon socket
  • 해결: 사용자를 docker 그룹에 추가 후 재로그인
    sudo usermod -aG docker $USER
# 재로그인 필요

3. CUDA 버전 불일치

  • 증상: 컨테이너에서 GPU를 인식하지 못함
  • 해결: 환경 변수 PATH 확인 및 CUDA 재설치

4. SSH 접속 불가

  • 증상: 원격 접속이 되지 않음
  • 해결: 네트워크 설정 및 SSH 서비스 상태 확인
    sudo systemctl status sshd
