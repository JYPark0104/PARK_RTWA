리뉴얼 Web Ray Tracing Agent 사용법
==========================================================================

--------------------------------------------------------------------------

--------------------------------------------------------------------------

      nohup 백그라운드로 상시 실행
    * 컨테이너는 --restart unless-stopped 라, 서버 재부팅돼도 컨테이너 자체는 자동으로 다시 뜸
- 접속 URL: http://165.132.192.78:5273/
    * 연세대 교내 WiFi 또는 VPN 연결 시 항시 접속 가능
    * 호스트 포트 5273 -> 컨테이너 5173, 8900 -> 8800 으로 매핑
      (이전 twin_minji 의 5173/8800 과 충돌 방지용으로 분리)

- 사용 모드: 단일 사용자 가정 (동시 잡 1개, 인증 없음 - 내부망 전용)

--------------------------------------------------------------------------
1. Sessions
--------------------------------------------------------------------------
- Scene 이름을 입력하고 '세션 생성' -> 모든 결과는 sessions/<uuid>/ 안에 격리 저장
- 기존 세션 '열기'(재활용) / '이름변경' / '삭제' 가능
    * 삭제 시 해당 세션 폴더의 모든 결과(NPZ/PNG/CSV 등)가 영구 삭제되므로 확인창이 한 번 뜸
- 작업 순서는 상단 탭(1->9)을 따라 진행

--------------------------------------------------------------------------
2. Scene
--------------------------------------------------------------------------
- '라이브러리에서 불러오기': 서버에 사전 보관된 .ply 맵을 드롭다운에서 선택 -> 불러오기
- '라이브러리 편집' 버튼:
    * 기존 라이브러리 맵 삭제
    * 새 .ply 맵 업로드 (이름 지정 가능, 미입력 시 파일명 사용)
- '직접 업로드': .obj / .ply / .zip(Mitsuba XML+PLY) 업로드 -> 자동으로 Sionna 호환 XML 변환
- '기본 재질' 선택: 현재 mesh 는 재질 calibration 이 안 된 상태라 재질이 학습되지 않음.
    -> mesh 전체를 어떤 재질로 볼지 하나로 결정 (itu_concrete 등)
- 3D 미리보기에서 회전/확대로 씬 확인
- 팁: 라이브러리에서 A 를 불러온 뒤 B 로 바꿔 불러와도 미리보기가 정상 갱신됨(메시 캐시 버그 수정됨)

--------------------------------------------------------------------------
3. TX / RX
--------------------------------------------------------------------------
- RX 배치 방식 (추천: ground_grid)
    * ground_grid: 씬 경계에서 하늘->지면으로 레이캐스팅해 지면 위에만 RX 를 자동 격자 배치.
                   들어오자마자 자동 미리보기됨
        - grid_n   : 한 축당 후보 수 (총 grid_n x grid_n). 키울수록 RX 가 촘촘 (RT 시간 증가)
        - RX 높이  : 지면(mesh)으로부터 이격 높이. 일반 단말 높이 1.5 m 기본
        - margin   : 경계 가장자리 제거 비율
    * 그 외 grid(AABB) / explicit / radial / street / clicks 방식도 선택 가능
- TX 배치: 지도에서 좌클릭
    * 클릭 지점의 mesh(지면)가 옅은 주황색 마커로 표시되고,
      거기서 일정 높이 이격된 공중에 빨간 TX 가 놓임
      (이격 높이는 4.RT 의 'TX 지면 이격' 값으로 조절)
    * 여러 대 배치 가능. TX 목록에서 '삭제' 버튼으로 개별 제거
- 마커가 작게 보이도록 크기 조정돼 있음 (씬 크기 비례)

--------------------------------------------------------------------------
4. RT
--------------------------------------------------------------------------
- 안테나 설정 (BS=TX, UE=RX)
    * SISO: BS 1x1 / UE 1x1
    * MIMO: 원하는 rows x cols (예: BS 16x16, UE 4x4). 안테나 포트 수 = 공분산 행렬 차원
- RT 엔진 토글 (피민지/종현 선배님 방식과 박준영 방식을 아직 통합 못 해 분기)
    (1) P1A Ray Tracing : 종현 선배님 코드 엔진. 251218 표준 NPZ 생성 ->
                          5.Metrics(공분산 등) 연산 가능
    (2) batch Ray Tracing: PARK 방식 batch RT. channel_data.npz 출력 + 시각화/Scenario 중심.
                           batch 모드에서만 batch_size(배치당 RX) 노출, metric 단계는 건너뜀
    -> 추후 두 엔진 통합 예정
- 'Ray Tracing 기본': 주파수, max_depth, seed, 경로 수 등 설정
- '고급 옵션 표시': PathSolver 플래그(LoS/specular/diffuse/refraction/diffraction 등),
                   num_samples, max_num_paths, TX 지면 이격[m],
                   RadioMaterial(scattering 계수/패턴), 안테나 패턴/편파 등 세부 조정
- Coverage Map: TX 광역 heatmap 옵션 (RadioMapSolver)

--------------------------------------------------------------------------
5. Metrics
--------------------------------------------------------------------------
- (피민지 선배님 part)
- channel data 를 분석할 metric 을 카테고리별 체크박스로 선택
  (RSRP/PDP/PADP/Marginal CCM/Separability/SU-MIMO Capacity/BM 등)
- 상단 프리셋(RT only / RT+CCM / SWOMP / BM Full 등) 중 하나 선택해도 OK
- metric 간 의존성은 자동 위상정렬되어 필요한 stage 가 순서대로 실행됨
- 참고: metric 은 P1A 엔진일 때 의미가 있음 (batch 엔진은 metric 건너뜀)

--------------------------------------------------------------------------
6. Run
--------------------------------------------------------------------------
- '잡 실행' -> 설정한 씬/TX/RX/RT 대로 Ray Tracing 수행
- 진행 표시
    * 상단: 전체 공정 진행 바
    * batch 엔진 시: TX별 배치 진행이 제자리 갱신되는 전용 바로 표시
      (TX 2/3, 배치 35/102, 누적 RX, 직전배치 유효, RSRP 범위). 로그 패널은 주요 이벤트만
    * 실시간 로그(WebSocket)
- 소요 시간 주의: 3.TX/RX 의 TX/RX 개수, 4.RT 의 안테나 수 / max_depth / num_samples 를
  크게 늘리면 시간이 급증
- 완료 후 '결과 보기' -> 7.RT Results 로 이동
- 단일 사용자 모드라 동시 잡은 1개만 실행됨

--------------------------------------------------------------------------
7. RT Results
--------------------------------------------------------------------------
이곳에서 Ray Tracing 결과를 확인. 섹션 순서:
  결과(헤더) -> 결과 파일 트리 -> Review -> RX Inspector

- 결과(첫 화면): Coverage Map / RSRP 결과.
    P1A 엔진 + 유효 metric 선택 시 활성화 (피민지 선배님 영역)
- 결과 파일 트리: 모든 output(npz/png/csv/usda/obj 등) 다운로드,
    우측 '미리보기'로 png/csv/json 즉시 확인
- Review - RT 결과 요약 (all TX): batch 엔진 시 활성화. 배치한 TX/RX 에 대해
    * 좌: 각 RX 위치의 RSRP 맵 (산점 + 건물 외곽 + 히스토그램)
    * 우: LoS/NLoS 맵 (LoS=초록, NLoS=주황, Dead=회색)
- RX Inspector (인터랙티브): 지도에서 RX 를 좌클릭하면 로딩 바 표시 후
    (~수십 초 ~ 2분) 해당 RX 의
    * PDP + 총 RSRP
    * PADP (3D 콩나물 차트: delay x AoA x 정규화 power)
    * Covariance (|R_RX|, |R_TX|)
    TX 전환 가능 (channel_data 필요 -> batch 엔진 결과여야 활성화)

--------------------------------------------------------------------------
8. Scenario
--------------------------------------------------------------------------
각 RX 격자에 계산된 RT 결과를 이용해, "사용자가 이 동선으로 움직이면 실시간으로
어떤 RT 결과가 나올지" 시나리오를 구성 (batch 엔진 산출물 USDA/OBJ 필요)

- 경로 그리기: 2D 탑뷰 지도에서 좌클릭 드래그 ->
    커서에 가장 가까운 RX 들이 순서대로 경로에 인덱싱/저장
    * z: 마지막 취소, r: 전체 초기화, TX 전환 가능
- 키프레임 설정
    * FPS            : 초당 재생 프레임 수
    * Frames per step: RX 하나당 유지 프레임 수
    * 추천: FPS=30, Frames per step=3 (RX당 0.1초)
- '시나리오 생성' -> 9번으로 이동

--------------------------------------------------------------------------
9. Scenario Results
--------------------------------------------------------------------------
- 내가 드래그한 경로대로 RX(초록)가 이동하며 Ray 를 어떻게 받는지 키프레임으로 재생
    * Ray 색: LoS=파랑 / NLoS=노랑, power 강할수록 굵게
              (직선 구간으로 벽면에서 정확히 꺾임)
    * 이동 경로: 연한 연두색 굵은 선으로 전체 궤적 표시
- 재생/일시정지 + 스텝 슬라이더, 확대/축소/회전/이동(OrbitControls) 가능
- 'blender_mobility.py' 다운로드: Blender 에서 그대로 재생할 수 있는 자체 완결형 스크립트
    사용법: (선택) Map_Mesh.obj Import -> Scripting 탭에서 스크립트 Run
            -> Layout 탭에서 Space bar 재생
