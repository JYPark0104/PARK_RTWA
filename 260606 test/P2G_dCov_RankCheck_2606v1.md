# P2G_dCov_RankCheck_2606v1.py

## 목적
저랭크 r 이 `d_Cov`(Bures-Wasserstein)에 주는 **실제 상대오차**를 측정해 적정 r 을
정량 근거로 확정한다. (단계 2 `d_Cov` 단위테스트 겸용)

## 왜 '꼬리 에너지'가 아니라 'd_Cov 오차'인가
꼬리 에너지 비율 != d_Cov 오차. BW 교차항 `‖S_iS_j‖_*` 에서 작은 고유값은
`sqrt(λ)`로 더 작아져 기여가 작다. 따라서 에너지가 아니라 d_Cov 자체 오차로 판정.

## 방법
1. 점 테이블에서 꼬리(cov_tail) 큰 K=5점(rows) + 참조 J=40점(cols) 선택.
2. 해당 점 원본 R_BS(1024²) 재로드 → full eigh(r=M) 인수 (모든 GPU 유틸).
3. `d_Cov`를 full 절사 r 별로 계산, full-rank 기준 상대오차 산출.
   `d_BW² = tr_i+tr_j − 2‖B_i^H B_j‖_*`, `d_Cov=sqrt(max(.,0))`.
4. 교차검증: 점 테이블 cov32 vs full 절사 r=32 가 일치하는지 확인.

## 결과 (2026-06-06, 점테이블 20260606_072539)
- 교차검증: 점테이블 r32 == full절사 r32, 최대차 3.2e-5 → 신뢰 가능
- d_Cov_full 범위: 0.338 ~ 1.402 (trace=1 정규화, 유효 220쌍)
- **수렴 곡선 (rel = |d_Cov_r − d_Cov_full| / d_Cov_full)**

  | 48 | 2.95e-3 | 7.33e-2 | 7.47e-3 | 408 |
  | 64 | 2.61e-3 | 2.34e-2 | 4.14e-3 | 544 |

## 해석 / 결정
- **중앙값**은 r=32에서도 0.44%로 작음. 문제는 **가까운 쌍(작은 d_Cov)의 최대오차**.
- 최대오차는 **r=96에서 처음 <1%**(0.91%), 이후 거의 평탄(r=512도 0.59%).
  → knee 는 r≈64~96. `rel_max<1e-3` 은 어떤 r로도 도달 불가(약 0.6% floor:
  εI 바닥 + 가장 가까운 쌍의 본질적 민감도). 따라서 PASS_REL=1e-3 은 과도하게 엄격.
- **권고: r=96** (최대 0.91%, p95 0.29%, 중앙 0.24%, 816MB). 가벼운 대안 r=64(최대 2.3%).
